# TFCI Geographic Assets

These assets are presentation-only. They do not define jurisdiction admission, legal status, sovereignty, scoring, capital, evidence or veto values. Runtime joins use canonical `tfciSlug` only.

- `tfci_jurisdiction_boundaries_simplified.geojson`: map geometry and point-marker fallbacks.
- `tfci_jurisdiction_centroids.json`: display coordinates and locator-map configuration.
- `tfci_geography_crosswalk.json`: TFCI slug to external geographic identifier mapping.
- `SOURCES.md`: source, license, retrieval and generation record.

The dashboard must display a neutral boundary disclaimer and provide a table equivalent to maps.
