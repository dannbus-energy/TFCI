# TFCI Documentation

This directory holds the human-readable, versioned documentation of the Transition Finance Credibility Index.

## Authority order

1. `TFCI_Manifesto_v0.1.md` — purpose and intellectual philosophy.
2. `TFCI_Standard_v0.7.md` — normative methodology and data/publication contract.
3. `TFCI_Visual_Language_and_Interface_Standard_v0.1.md` — governed visual representation.
4. `TFCI_Dashboard_Component_Catalog_v0.1.md` — component implementation contract.
5. `TFCI_Accessibility_and_Map_Policy_v0.1.md` — interaction and geographic policy.
6. `TFCI_Design_Decision_Log.md` — dated design decisions.

The Standard prevails in conflicts. Documentation is versioned with the release; mockups are implementations, not authorities.
