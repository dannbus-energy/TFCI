# ADR-0001: Record architecture decisions as ADRs

Status: Accepted
Context: TFCI is growing from a governed CSV pipeline into a production
application; decisions are scattered across chat logs and the design
decision log.
Decision: Every architecturally significant choice gets a short, dated,
one-decision-per-file ADR in docs/adr/.
Consequences: Slight writing overhead; huge payoff in institutional memory
for collaborators and funders.
